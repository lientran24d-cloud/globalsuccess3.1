II NGỮ PHÁP (GRAMMAR)

1. This (Chỉ người/vật ở gần)

  • Khẳng định: This + is + name.
    hoặc This + is + a/an + Danh từ số ít.
  • Hỏi: Is + this + name?
    hoặc Is + this + a/an + Danh từ số ít?
  • Trả lời: Yes, it is. / No, it isn't.

2. That (Chỉ người/vật ở xa)

  • Khẳng định: That + is + name.
    hoặc That + is + a/an + Danh từ số ít.
  • Hỏi: Is + that + name?
    hoặc Is + that + a/an + Danh từ số ít?
  • Trả lời: Yes, it is. / No, it isn't.
